# Starz Promosyon Telegram Bot

A simple Telegram bot for Starz Promosyon, focused on fashion, clothing, promotions, and basic contact information.

## Setup

1. Create a bot with Telegram's BotFather and copy the bot token.
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Set the `BOT_TOKEN` environment variable.
4. Run:

```bash
python bot.py
```

The bot provides `/start` and `/help` plus a small inline-button menu.
